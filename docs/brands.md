# Brand capability limits

The public REST reference does not offer equivalent operations for the old `get_brand` and `list_brands` tools. These tools and the brand entity resource are not registered.

Brand templates are different resources; their metadata does not constitute a complete Brand Kit record of colors, fonts, and logos. This server does not substitute brand templates for Brand Kits.

See [Brand templates](https://www.canva.dev/docs/apps/rest-apis/reference/brand-templates/).
